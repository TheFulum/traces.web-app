Импорт мест

Загрузите JSON (массив) или CSV из экспорта. Не более 50 строк. Новые id создаются без вопросов; при совпадении id с базой нужно выбрать действие или нажать «Перезаписать все конфликты».

Для строк с конфликтом id выберите действие или используйте массовую перезапись. Кнопка «Перезаписать» на строке затирает документ в базе данными из файла.
