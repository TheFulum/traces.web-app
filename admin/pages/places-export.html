Экспорт мест

Выгрузка списка мест в JSON или CSV. Период считается по дате последнего изменения в базе (updatedAt), если её нет — по дате создания (createdAt). Места без этих полей не попадают в выборку по периоду.

Переводы: в JSON объект i18n совпадает с вкладками RU/EN в форме места (русский также продублирован в корневых полях name, description и т.д.). В CSV есть отдельные колонки name_en, description_en, … и полный i18n_json для восстановления структуры.
